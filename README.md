# js-hello-world

Навчальний JavaScript-проєкт для лабораторної роботи №1 з дисципліни APKS.

## Варіант

- Варіант 3
- Мова: JavaScript
- Система складання: npm scripts
- Фреймворк тестування: Jest
- Група: КІ-406
- Автор: Oleh Oprysk

## Запуск

Встановіть залежності та запустіть застосунок:

```sh
npm install
npm start
```

Застосунок виводить привітання та результат обчислення `2 + 2`.

## Перевірки

```sh
npm run build
npm test
```
